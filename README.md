# 코디세이 1-2: Python 기초
# Quiz Game

## 1. 프로젝트 개요
이 프로젝트는 **터미널(콘솔)에서 실행되는 Python 퀴즈 게임**입니다.  
사용자는 메뉴를 통해 퀴즈를 풀고, 새로운 퀴즈를 추가하고, 저장된 퀴즈 목록과 최고 점수를 확인할 수 있습니다.

이 프로젝트의 목표는 다음과 같습니다.

- Python 기본 문법을 활용한 입력/출력 흐름 구현
- 클래스 기반 구조(`Quiz`, `QuizGame`)로 역할 분리
- JSON 파일 저장/불러오기를 통한 데이터 영속성 구현
- Git/GitHub를 활용한 버전 관리 경험

---

## 4. 주요 기능
이 프로그램은 아래 기능을 제공합니다.

1. **퀴즈 풀기**
   - 저장된 퀴즈를 순서대로 출제
   - 사용자의 정답 입력 처리
   - 각 문제에 대해 정답/오답 안내
   - 전체 문제 풀이 후 최종 점수 출력
   - 최고 점수와 비교 후 필요 시 갱신

2. **퀴즈 추가**
   - 문제, 선택지 4개, 정답 번호를 입력받아 새 퀴즈 등록
   - 등록 후 `state.json`에 저장

3. **퀴즈 목록 보기**
   - 현재 저장된 퀴즈 목록 출력
   - 퀴즈가 없으면 안내 메시지 출력

4. **최고 점수 확인**
   - 현재 저장된 최고 점수 출력
   - 아직 퀴즈를 풀지 않은 경우 별도 안내

5. **프로그램 종료**
   - 종료 전 가능한 범위에서 데이터 저장
   - 안전하게 프로그램 종료

## 6. 입력 처리 및 예외 처리 기준
이 프로젝트는 아래 입력/예외 처리 규칙을 따릅니다.

### 공통 입력 처리
- 입력값의 앞뒤 공백을 제거한 후 처리
- 빈 입력인 경우 안내 메시지 출력 후 재입력
- 숫자 입력이 필요한 곳에서 숫자 변환 실패 시 안내 후 재입력
- 허용 범위를 벗어난 숫자 입력 시 안내 후 재입력

### 처리 대상 예시
- 메뉴 선택
- 퀴즈 정답 입력
- 퀴즈 추가 시 정답 번호 입력

### 예외 처리
- `Ctrl+C (KeyboardInterrupt)` 발생 시 비정상 종료하지 않음
- `EOFError` 발생 시 비정상 종료하지 않음
- 가능한 범위에서 저장 후 안전 종료
- `state.json` 파일이 없으면 기본 퀴즈 데이터를 사용
- `state.json` 파일이 손상되었으면 안내 후 기본 데이터로 복구 또는 초기화

## 7. 클래스 설계

### 7-1. `Quiz` 클래스
개별 퀴즈 1개를 표현하는 클래스입니다.

#### 속성
- `question`: 문제
- `choices`: 선택지 목록 (기본 4개)
- `answer`: 정답 번호 (1~4)

#### 메서드
- `display()`: 문제와 선택지 출력
- `is_correct(user_answer)`: 사용자의 답이 정답인지 확인
- `to_dict()`: JSON 저장용 딕셔너리 변환
- `from_dict(data)`: 딕셔너리 데이터를 `Quiz` 객체로 변환

---

### 7-2. `QuizGame` 클래스
게임 전체를 관리하는 클래스입니다.

#### 속성
- `quizzes`: 퀴즈 목록
- `best_score`: 최고 점수

#### 메서드
- `run()`: 프로그램 전체 실행
- `show_menu()`: 메뉴 출력
- `play_quiz()`: 퀴즈 진행
- `add_quiz()`: 새 퀴즈 추가
- `list_quizzes()`: 퀴즈 목록 출력
- `show_best_score()`: 최고 점수 출력
- `load_state()`: `state.json` 불러오기
- `save_state()`: `state.json` 저장하기
- `get_valid_number_input()`: 숫자 입력 검증용 공통 메서드

## 9. 데이터 파일 설명 (`state.json`)
이 프로젝트는 프로그램 종료 후에도 데이터를 유지하기 위해  
프로젝트 루트의 `state.json` 파일을 사용합니다.

### 저장 위치
- `./state.json`

### 인코딩
- UTF-8

### 저장 데이터
- `quizzes`: 퀴즈 목록
- `best_score`: 최고 점수

### 예시 스키마
```json
{
  "quizzes": [
    {
      "question": "Python에서 리스트를 만드는 기호는?",
      "choices": ["()", "{}", "[]", "<>"],
      "answer": 3
    }
  ],
  "best_score": 4
}
```

### 동작 규칙
- 파일이 없으면 기본 퀴즈 데이터 사용
- 파일이 손상되었으면 안내 메시지 출력 후 기본 데이터로 복구 또는 초기화
- 퀴즈 추가 또는 최고 점수 갱신 시 저장

## 10. 기본 퀴즈 데이터 요구사항
- 선택한 주제의 퀴즈를 **5개 이상** 작성
- 각 퀴즈는 다음 정보를 포함
  - 문제
  - 선택지 4개
  - 정답 번호 (1~4)
- 기본 퀴즈는 프로그램 첫 실행 시 사용할 수 있어야 함
